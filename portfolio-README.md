A modern, responsive personal portfolio website built to showcase my projects, skills, education, and professional profile as a Full Stack Developer.

## ✨ Features

- 🎨 Clean, modern UI with smooth scroll-reveal animations
- 🌓 Light / Dark theme toggle
- 📱 Fully responsive design (mobile, tablet, desktop)
- ⌨️ Typing animation for role/title in the hero section
- 🧩 Sectioned layout — Home, About, Skills, Projects, Education, Certifications, Contact
- 📄 Downloadable resume button
- 🖱️ Interactive project cards with live demo & GitHub links
- 🎞️ Scrolling tech marquee for skills

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/abhinavTechii/portfolio.git

# Navigate into the project folder
cd portfolio

# Open index.html in your browser
# (or use the Live Server extension in VS Code)
```

No build tools or dependencies required — it's a pure HTML/CSS/JS static site.
